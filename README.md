# KOVA, site vitrine (POC)

Page unique en HTML/CSS pur (aucune dépendance, aucun build). Les polices viennent de Google Fonts.

## Publier sur GitHub Pages (lien gratuit)
1. Créer un dépôt GitHub (public) et y pousser ce dossier tel quel.
2. Settings > Pages > Source : "Deploy from a branch", branche `main`, dossier `/ (root)`.
3. Le site est en ligne au bout d'une minute sur `https://<ton-compte>.github.io/<nom-du-depot>/`.

## Contenu
- `index.html` : la landing (intro animée, 3 collections + basiques, liste d'attente factice).
- `images/` : rendus 3D des casquettes et visuels des motifs.

## À savoir
- Les visuels de casquettes sont des rendus 3D, pas des photos.
- Les prix sont des placeholders `[PRIX €]`, le formulaire e-mail ne fait rien.
- Les noms et motifs ne sont pas encore vérifiés à l'INPI / EUIPO.
